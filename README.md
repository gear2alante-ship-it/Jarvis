# Jarvis

Jarvis is an AI assistant web application built with React, TypeScript, and Vite.

## User Profile Page

The user profile page provides a comprehensive view and management interface for a user's account, including:

- **Profile header** — cover image, avatar with online-status indicator, display name, username, role, join date, and Edit Profile action
- **Stats cards** — at-a-glance KPIs: Conversations, Tasks Completed, Integrations, and Hours Saved
- **Personal Information** — editable fields (full name, email, phone, location, job title, department, website, bio)
- **Recent Activity** — timestamped feed of the user's latest conversations, tasks, and integrations
- **Connected Accounts** — toggle connections to external services (GitHub, Slack, Google, Notion, …)

## Development

```bash
npm install
npm run dev      # start dev server at http://localhost:5173
npm run build    # production build
npm run lint     # ESLint check
```
